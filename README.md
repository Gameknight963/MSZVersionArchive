## Miside Zero versions archive

### Why does this exist?

itch.io doesn't have a useful API.
Developers didn't respond to my request to 
upload builds to Releases, so I did it myself.

### Why is there no source code?

Because the game isn't open source. Duh.

### Warning
The file structure of releases in this repo differs from 
what is distributed on the offical itch page.

The top level folder has been removed for simplicity.

Example:

**Offical:**
```
└───MiSide Zero Alpha.zip
    └───MiSide Zero Alpha
        └───MiSide Zero_Data
            ├───il2cpp_data
            ├───Plugins
            ├───Resources
            └───StreamingAssets
```

**This repo**
```
└───MiSide Zero Alpha 0.72.zip
    └───MiSide Zero_Data
        ├───il2cpp_data
        ├───Plugins
        ├───Resources
        └───StreamingAssets
```
